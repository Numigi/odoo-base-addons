======================
Document URL Chatter List
======================

.. image:: https://img.shields.io/badge/licence-LGPL--3-blue.svg
   :target: http://www.gnu.org/licenses/lgpl-3.0-standalone.html
   :alt: License: LGPL-3

This module enhances the chatter component in Odoo to display URL attachments in a dedicated list.

Features
--------

* Keeps the standard display of attachments
* Adds a separate section showing only URL attachments
* Works globally on all form views with chatter
* Utilizes OWL framework for integration

Installation
-----------

This module depends on the ``document_url`` module from OCA.

Configuration
------------

No configuration is needed. After installation, URL attachments will automatically be displayed in a dedicated section within the chatter.

Usage
-----

1. Navigate to any form view with a chatter (for example, a project task)
2. Add a URL attachment using the "Attach URL" button provided by the document_url module
3. The URL will appear both in the regular attachments section and in the dedicated URL section
4. Click on the URL in the dedicated section to open it in a new tab
